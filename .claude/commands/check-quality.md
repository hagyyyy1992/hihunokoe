---

プロジェクトのコード品質を包括的にチェックし、改善点をレポートします。

## チェック項目

1. **型チェック**: TypeScriptのコンパイルエラーを検出
2. **リンター**: ESLintルール違反を確認
3. **フォーマット**: Prettierフォーマット違反を検出
4. **テスト**: テストカバレッジとテスト結果を確認
5. **依存関係**: 未使用・重複・脆弱性のある依存関係を検出

## 実行コマンド

以下のコマンドを順次実行します：

```bash
# TypeScript型チェック
npx tsc --noEmit

# ESLintチェック
npm run lint

# フォーマットチェック
npm run format:check

# テスト実行
npm test -- --coverage

# 依存関係の監査
npm audit
```

## レポート内容

- 各チェックの合格/不合格状態
- 発見された問題の詳細と修正方法
- コード品質スコア（A-F評価）
- 改善のための具体的なアクションアイテム
