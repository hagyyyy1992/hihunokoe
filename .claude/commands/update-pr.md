description: 現在のブランチのPRタイトルとディスクリプションを更新
---

現在のブランチに対応するPRのタイトルとディスクリプションを、コミット履歴と差分から自動的に更新します。

## 機能

- 現在のブランチのPRを自動検出
- コミット履歴から最も重要な変更を抽出してタイトルを生成
- 変更内容を分析してディスクリプションを更新
- APIの変更、UIの変更、テストの変更、ドキュメントの変更を自動分類

## 使用方法

```bash
# 現在のブランチのPRを更新
/update-pr

# PR番号を指定して更新（オプション）
/update-pr 60
```

## 更新内容

### タイトル

- feat > fix > refactor の優先順位で最も重要な変更を反映
- 日本語のコミットメッセージ形式を維持

### ディスクリプション

- **Summary**: 主要な変更のサマリー（最大5件）
- **Changes**: API、UI、テスト、ドキュメントの変更を分類表示
- **Statistics**: コミット数、変更ファイル数、追加/削除行数
- **Recent Commits**: 最新10件のコミット履歴
- **Test plan**: テスト実行状況のチェックリスト

## 実行後

更新完了後、PRのURLが表示されます。
