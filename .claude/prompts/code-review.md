# Code Review Prompt

## Context

このプロンプトは、Usakaプロジェクトにおけるコードレビューを効率的に行うために使用します。

## Instructions

以下の観点でコードをレビューしてください：

### セキュリティ

- 認証・認可の適切な実装
- SQLインジェクション、XSS対策
- 秘密情報の適切な管理
- レート制限の実装

### パフォーマンス

- データベースクエリの最適化
- N+1問題の回避
- キャッシュ戦略
- 不要な再レンダリングの防止

### コード品質

- TypeScript型安全性
- エラーハンドリング
- テストカバレッジ
- コード重複の排除

### アーキテクチャ

- 責任の分離
- 依存関係の管理
- APIエンドポイントの設計
- データベース設計の一貫性

## Example Usage

```
このコードをレビューして：
[コードを貼り付け]

観点：
- セキュリティ面での問題
- パフォーマンスの改善点
- コード品質の向上
```
