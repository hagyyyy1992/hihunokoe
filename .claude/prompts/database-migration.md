# Database Migration Prompt

## Context

Usakaプロジェクトでデータベースマイグレーションを安全に実行するためのガイドです。

## Instructions

データベース変更時は以下の手順に従ってください：

### 1. 変更計画

- スキーマ変更の影響範囲
- ダウンタイムの要否
- データ移行の必要性
- ロールバック戦略

### 2. マイグレーション作成

- Prisma schema.prisma 更新
- マイグレーション生成: `npx prisma migrate dev`
- SQL の確認とカスタマイズ
- データ移行スクリプト（必要に応じて）

### 3. テスト環境での検証

- ローカル環境でのテスト
- データ整合性の確認
- パフォーマンス影響の測定
- アプリケーション動作確認

### 4. 本番適用準備

- バックアップ戦略
- ダウンタイム計画
- ロールバック手順
- モニタリング準備

### 5. 適用後の確認

- データ整合性チェック
- アプリケーション動作確認
- パフォーマンス監視
- エラーログ確認

## Safety Checklist

- [ ] バックアップ取得済み
- [ ] ロールバック手順確認済み
- [ ] テスト環境で検証済み
- [ ] 影響範囲を関係者に共有済み
- [ ] ダウンタイム（必要時）を事前通知済み

## Example Usage

```
以下のデータベース変更を実装してください：
変更内容: [スキーマ変更の詳細]
理由: [変更が必要な理由]
影響: [予想される影響]

考慮事項：
- 既存データの移行
- パフォーマンスへの影響
- ダウンタイムの最小化
```
