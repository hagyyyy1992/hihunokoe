# Feature Implementation Prompt

## Context

Usakaプロジェクトに新機能を実装する際の標準的なアプローチを定義します。

## Instructions

新機能を実装する際は、以下の手順に従ってください：

### 1. 要件分析

- ユーザーストーリーの理解
- 技術要件の洗い出し
- データベース設計への影響
- 既存機能との整合性

### 2. 設計

- API エンドポイント設計
- データベーススキーマ更新
- フロントエンド コンポーネント設計
- 認証・権限要件

### 3. 実装順序

1. データベース マイグレーション
2. API エンドポイント実装
3. フロントエンド コンポーネント
4. 統合テスト
5. E2E テスト

### 4. 品質チェック

- TypeScript 型チェック
- Jest ユニットテスト
- Playwright E2E テスト
- セキュリティ チェック

### 5. ドキュメント更新

- API ドキュメント
- コンポーネント仕様
- CLAUDE.md 更新（必要に応じて）

## Example Usage

```
以下の機能を実装してください：
[機能要件]

考慮事項：
- 既存の認証システムとの統合
- データベース設計への影響
- セキュリティ要件
- パフォーマンス要件
```
