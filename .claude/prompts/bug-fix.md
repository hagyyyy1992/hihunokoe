# Bug Fix Prompt

## Context

Usakaプロジェクトでバグ修正を行う際のアプローチを標準化します。

## Instructions

バグ修正時は以下の手順で対応してください：

### 1. 問題の理解

- バグの再現手順を確認
- 影響範囲の特定
- ログ・エラーメッセージの分析
- 期待動作と実際動作の比較

### 2. 根本原因分析

- コードパスの追跡
- データフローの確認
- 依存関係の影響
- 環境固有の問題

### 3. 修正戦略

- 最小限の変更で修正
- 副作用の回避
- テストでの検証可能性
- ロールバック容易性

### 4. 実装と検証

- 修正実装
- ユニットテスト追加/更新
- 統合テスト実行
- 回帰テスト実行

### 5. 予防策

- 類似バグの防止策
- テストカバレッジ向上
- コードレビュー観点追加
- ドキュメント更新

## Example Usage

```
以下のバグを修正してください：
症状: [バグの症状]
再現手順: [手順]
期待動作: [期待される動作]
環境: [発生環境]

調査観点：
- ログの確認
- 関連コードの分析
- テストの追加
```
