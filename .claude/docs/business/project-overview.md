# プロジェクト概要

## サービス名

**Usaka（ウサカ）** - 化粧品体験共有コミュニティ

## ビジョン

化粧品選びで失敗する人をゼロにする。体験ベースのリアルな情報共有で、一人ひとりに最適な化粧品との出会いを創出する。

## ミッション

成分表や点数評価ではなく、実際の使用感や肌の変化に基づいた体験談を共有できるプラットフォームを提供し、化粧品選びの新しいスタンダードを作る。

## 問題設定

### 現在の課題

1. **情報の信頼性不足**: 既存のレビューサイトは広告性が高く、リアルな体験談が埋もれがち
2. **個人差への配慮不足**: 肌質・季節・体調などの個人的要因が考慮されていない
3. **ネガティブ体験の共有しにくさ**: 「合わなかった」体験が批判的に受け取られがち
4. **専門知識の壁**: 成分分析に基づく情報は一般ユーザーには難しすぎる

### ターゲットユーザーの悩み

- 化粧品を購入しても肌に合わないことが多い
- レビューサイトの情報が自分に当てはまらない
- 同じ肌質の人の意見を聞きたいが見つからない
- 失敗体験を参考にしたいが、そういった情報が少ない

## ソリューション

### 核となる価値提案

1. **体験重視のアプローチ**: 成分分析より実際の使用感を重視
2. **心理的安全性**: ネガティブ体験も歓迎する文化づくり
3. **個人化された情報**: 肌質・状況・季節に応じた絞り込み
4. **共感ベースのコミュニティ**: 批判ではなく共感を軸とした交流

### 差別化ポイント

- **「合わなかった」体験も価値ある情報**として扱う
- **肌質・季節・体調**などの状況を詳細に記録
- **広告っぽさを排除**した純粋な体験共有
- **専門知識不要**で誰でも参加できる敷居の低さ

## 市場機会

### 市場規模

- 化粧品市場: 約2.7兆円（日本国内）
- 美容・コスメ情報検索: 月間数千万PV
- 20代女性のSNS利用率: 95%以上

### 競合状況

- **@cosme**: 老舗だが情報が多すぎて整理されていない
- **LIPS**: InstagramライクだがインフルエンサーMarketingが中心
- **楽天・Amazon**: 購入前提のレビューで使用感情報が浅い

### 参入機会

- 既存サービスは「評価」中心で「体験」が軽視されている
- 個人の状況に応じた情報提供が不十分
- コミュニティの心理的安全性が確保されていない

## 事業戦略

### フェーズ1: MVP（〜3ヶ月）

- 基本的な投稿・閲覧機能
- 肌質別・カテゴリ別フィルタ
- 小規模コミュニティでの検証

### フェーズ2: コミュニティ拡張（〜6ヶ月）

- 共感・コメント機能
- おすすめ機能
- ユーザー獲得施策

### フェーズ3: データ活用（〜12ヶ月）

- 個人化レコメンド
- トレンド分析
- ブランド向けインサイト提供

### 長期ビジョン

- 化粧品選びのデファクトスタンダード
- パーソナライズされた美容アドバイス
- メーカーとユーザーの新しい関係性構築
