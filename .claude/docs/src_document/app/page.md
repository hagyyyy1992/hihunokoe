# page.tsx

## 概要

ひふのこえサービスのランディングページ（ホームページ）コンポーネント。訪問者にサービスの価値を伝え、登録を促すためのインタラクティブなページです。

## 主要機能

### 1. ヒーローセクション

- キャッチコピー「本音のコスメ体験、見つけよう」
- 「今すぐ始める」「体験談を見る」のCTAボタン
- フェードインアニメーション

### 2. 特徴セクション

3つの主要な価値提案を紹介：

- **体験重視の投稿**: 使用感や変化を詳しく共有
- **安心して投稿**: 匿名投稿オプション
- **肌質別検索**: 自分に合った体験を見つける

### 3. 利用ステップガイド

1. 無料会員登録
2. 体験を投稿
3. 他のユーザーと共感
4. 自分に合うコスメを発見

### 4. ユーザーの声

実際の利用者からのフィードバックを表示（デモデータ）

### 5. 統計情報

- 投稿数: 5,000件以上
- ユーザー数: 10,000人以上
- 共感数: 50,000件以上

### 6. FAQセクション

よくある質問と回答を提供

## インタラクティブ要素

### スクロール進行インジケーター

```typescript
const scrollPercentage = (scrollY / (scrollHeight - clientHeight)) * 100
```

ページのスクロール進行状況を視覚的に表示

### セクションアニメーション

Intersection Observerを使用して、各セクションのフェードイン効果を実装

### スムーズスクロール

「今すぐ始める」ボタンクリックで登録セクションへスムーズスクロール

## 状態管理

- `scrollProgress`: スクロール進行状況（0-100%）
- `visibleSections`: 表示されているセクションのSet

## パフォーマンス最適化

- Intersection Observerによる遅延アニメーション
- スクロールイベントの効率的な処理
- クリーンアップ処理でメモリリークを防止

## 依存関係

- React hooks (useState, useEffect)
- Next.js Link コンポーネント
- `@/lib/constants`: SERVICE_NAME定数

## スタイリング

- Tailwind CSSによるレスポンシブデザイン
- グラデーション、シャドウ、アニメーション効果
- モバイルファーストアプローチ
