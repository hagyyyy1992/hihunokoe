# auth/forgot-password/page.tsx

## 概要

パスワードを忘れたユーザー向けのパスワードリセット開始ページ。メールアドレスを入力してリセットリンクを受け取る機能を提供します。

## 機能詳細

### フォーム構成

- **メールアドレス入力**: 登録済みメールアドレスを入力
- シンプルな単一フィールドフォーム

### 処理フロー

1. **メールアドレス送信**

   ```typescript
   POST / api / auth / forgot - password
   {
     email: string
   }
   ```

2. **レスポンス処理**

   - 成功時：確認メッセージを表示
   - エラー時：エラーメッセージを表示

3. **セキュリティ考慮**
   - メールアドレスの存在有無に関わらず同じメッセージを表示
   - タイミング攻撃への対策

## 状態管理

| State       | 型      | 説明                     |
| ----------- | ------- | ------------------------ |
| `email`     | string  | 入力されたメールアドレス |
| `message`   | string  | 成功メッセージ           |
| `error`     | string  | エラーメッセージ         |
| `isLoading` | boolean | 送信処理中フラグ         |

## UI/UX設計

### メッセージ表示

```typescript
{message && (
  <div className="bg-green-50 border border-green-200 text-green-700">
    {message}
  </div>
)}
```

- 成功：緑色の背景でポジティブなフィードバック
- エラー：赤色の背景で注意を促す
- ローディング中はボタンを無効化

### レイアウト

- センターレイアウト
- モバイルレスポンシブ対応
- ブランドロゴ表示

## セキュリティのベストプラクティス

1. **情報漏洩防止**

   - 登録済みメールかどうかを露出しない
   - 一律で「メールを送信しました」と表示

2. **レート制限**

   - API側でレート制限を実装（想定）
   - 連続リクエストの防止

3. **トークンベース**
   - 実際のリセットは安全なトークンで実行

## 関連機能

- `/auth/reset-password`: パスワードリセット実行ページ
- `/auth/login`: ログインページ（戻るリンク）
- メール送信システム（Resend/MailHog）

## エラーハンドリング

- ネットワークエラー
- サーバーエラー
- バリデーションエラー

## テストポイント

- 有効なメールアドレス形式
- 空欄送信の防止
- 成功/エラーメッセージの表示
- ローディング状態の確認
