# src ディレクトリドキュメント

このディレクトリにはHihunokoeアプリケーションのソースコードのドキュメントが含まれています。

## ディレクトリ構造

```
src/
├── app/          # Next.js App Router のページとAPIルート
├── components/   # 再利用可能なReactコンポーネント
├── lib/          # ユーティリティ関数とライブラリ
├── hooks/        # カスタムReactフック
├── types/        # TypeScript型定義
└── middleware.ts # Next.jsミドルウェア
```

## 主要なディレクトリ

### /app

Next.js 15のApp Routerを使用したアプリケーションのコア部分。ページコンポーネント、レイアウト、APIルートが含まれています。

### /components

UIコンポーネント、フォーム、レイアウトなどの再利用可能なReactコンポーネント。

### /lib

認証、データベース接続、メール送信などのコアライブラリとユーティリティ関数。

### /hooks

コメント機能やパスワード表示切り替えなどのカスタムReactフック。

### /types

アプリケーション全体で使用されるTypeScript型定義。

## 関連ドキュメント

各ディレクトリとファイルの詳細なドキュメントは、それぞれのサブディレクトリ内にあります。
